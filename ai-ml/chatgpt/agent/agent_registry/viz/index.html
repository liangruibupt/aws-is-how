❌ Before — no registry

  • No authoritative inventory — nobody knows what exists or who owns it.
  • Teams rebuild tools that already exist → duplicated effort & cost.
  • No review gate — unvetted, shadow agents run in production.
  • No audit trail — can't trace a failure to a version or owner.

✅ After — with Agent Registry

  • One governed catalog; every record has an owner & lineage.
  • Consumers find approved capabilities by intent in seconds.
  • Curator approval gate + statusReason on every transition.
  • Full CloudTrail audit; EventBridge fires the approval workflow.
Data is simulated but shaped to the live API (verified 2026-09-16, us-east-1). Governance plane holds all states; discovery plane returns APPROVED only, and only records that clear a relevance floor — an unrelated query returns nothing rather than a zero-score record. (Note: the real API ranks by embedding similarity; this demo approximates it with keyword scoring.)
