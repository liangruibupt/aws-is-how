# 01 · 临《兰亭集序》—— 神龙本逐笔临写网页动画

以唐 冯承素 摹本（神龙本）的墨迹扫描为范本，一管毛笔在宣纸长卷上**逐笔**临写王羲之《兰亭集序》全篇 28 行、324 字，写毕落款、钤印、全卷展开。

纯静态网页：HTML + CSS + 原生 ES Module + Canvas 2D，无框架、无构建步骤。字形数据由 `tools/` 下的 Python 管线从扫描图中提取。

## 看点

| | |
|---|---|
| **逐笔还原** | 每个字从扫描图中切出，骨架化后推出笔路（共 2,562 笔），再按“先左后右、先上后下”的书写习惯排序。笔沿笔路落笔、行笔、提按、收笔，笔过之处依原帖墨色逐步显出 |
| **毛笔** | 湘妃竹管羊毫笔，略带透视。笔锋随按压铺开、随行笔方向拖曳，提笔时收拢离纸，并有投影 |
| **原帖本色** | 「崇山」二字是书毕后的旁添小字，动画里也在第四行写完后才补上。第 25 行的涂抹墨团照写。「因」「向之」「痛」「夫」「文」的改笔会弹出注释 |
| **廿之** | 全篇 20 个「之」字无一雷同：点「廿之」可让 20 个同时临写对照，有改笔的一张标「改」 |
| **透影 / 对帖** | 范本墨迹以可调浓淡衬在纸下（透影）；按住 `M` 或「对帖」时换成神龙本原图（含历代鉴藏印） |
| **运镜** | 开篇近观笔锋，随第一行书写渐渐退到整行，落款、钤印时再近观，最后展开全卷。长卷随书写向左展开，右端是包首、题签、锦带与玉别子 |
| **钤印** | 程序生成的寿山石印（印文「永和」取自原帖字形），按斜视透视落下、按实、提起，影子随离纸高度变淡变散 |
| **笔声** | 可选的 WebAudio 粉红噪声，音量随行笔速度与按压变化，钤印时有一声闷响 |
| **释文** | 右下为竖排释文，已写的字点亮、当前字标朱，点任意字即可跳到该处 |

全篇按 1× 自然速度约 11 分钟，默认 2×。

## 运行

ES Module 需要经 HTTP 打开（`file://` 不行）：

```bash
cd ai-ml/chatgpt/claude/opus55-showcase/01-lantingxu
python3 -m http.server 8765
# 浏览器打开 http://localhost:8765/
```

字体 [LXGW WenKai TC（霞鹜文楷 TC）](https://github.com/lxgw/LxgwWenkaiTC) 经 jsDelivr 加载。离线时会退回系统楷体，动画本身不受影响。

### URL 参数

| 参数 | 说明 | 例 |
|---|---|---|
| `autoplay` | 跳过开卷页直接开始 | `?autoplay` |
| `paused` | 与 `autoplay` 合用：进入后先不走笔 | `?autoplay&paused` |
| `speed` | 播放速度（默认 2） | `?speed=4` |
| `view` | `auto`（运镜，默认）/ `near` / `col` / `all` | `?view=col` |
| `c` | 从第 *n* 个字开始（0 起算，按原帖字序） | `?c=200` |
| `t` | 从时间轴第 *t* 秒开始（1× 时间） | `?t=300` |
| `trace` | 透影浓淡 0–0.6（默认 0.07） | `?trace=0.25` |

### 操作

| 操作 | 作用 |
|---|---|
| `空格` | 行笔 / 停笔 |
| `←` / `→` | 下一行 / 上一行（行序右起） |
| 按住 `M` 或「对帖」 | 显示神龙本原图 |
| `F` | 全卷 ↔ 运镜 |
| 拖拽 / 滚轮 | 自由平移、缩放；双击回到运镜 |
| 点释文中的字 | 跳到该字 |
| `Esc` | 关闭「廿之」 |

## 实现

```
01-lantingxu/
├── index.html          页面骨架：题签、计数、控制列、释文、廿之、开卷页
├── style.css           直书排版与界面
├── js/
│   ├── main.js         时间轴、运镜、长卷展开、渲染循环、交互
│   ├── anim.js         单字动画：笔路节奏（落笔/行笔/提按/空中移动）与墨迹遮罩显现
│   ├── brush.js        毛笔绘制（笔管、笔斗、笔头、投影）
│   ├── textures.js     程序生成：宣纸、绫、锦、毡、包首题签、「永和」印
│   └── sound.js        笔声
├── assets/             管线产物（前端只读这三个文件）
│   ├── lanting.json    325 个字（含墨团）的位置、字框、笔路 [x, y, r]
│   ├── ink-atlas.png   每字墨色浓度图集（灰度＝透明度）
│   └── model.jpg       神龙本扫描，供「对帖」
├── source/LantingXu.jpg   原始扫描（4513×1480）
└── tools/              字形提取管线
```

**渲染要点**
- 世界坐标就是扫描像素，所以笔路、墨迹、范本三者天然对齐。
- 每个字写时，以笔路为遮罩逐步显出墨迹图集中该字的墨色，写完再补上笔路没覆盖到的墨，然后“烘”进墨层，此后不必重绘。
- 未干的墨另有一层湿润光泽，会慢慢收干。
- 跳转（`seek`）时按时间轴重建墨层，所以任意跳转都与顺序播放结果一致。

### 字形管线

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install numpy scipy scikit-image opencv-python-headless pillow

python tools/segment.py   # Step 1：墨迹遮罩 → 分行（投影谷值）→ 分字（连通域 + 按释文字数切分）
python tools/strokes.py   # Step 2：骨架化 → 图 → 剪枝 → 笔画排序、重采样 → 写出 assets/
```

- `tools/text.py`：释文，按原帖行款分成 28 行，`〼` 表示墨团。
- `tools/overrides.json`：目视核对后的手工修正，包括部分行的切线、粘连字的拆分，以及像素归属。
- `segment.py` 会在 `tools/work/` 输出字表拼图 `sheet_*.png`，供人工核对切分结果。拼图用的字体路径是 macOS 的 STHeiti，其他系统请修改 `contact_sheets()`。
- `tools/work/` 是中间产物，已加入 `.gitignore`。

## 局限

- 笔顺是从骨架**推断**的，符合一般书写习惯，但不是王羲之真实的笔顺。连笔、牵丝处偶有顺序不自然。
- 墨色直接取自原帖扫描，所以这是按推断笔路“重演”原帖，而不是物理模拟笔墨。
- 窄屏（< 980px）时隐藏释文面板。
