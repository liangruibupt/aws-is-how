# 02 · 大力神 —— 六名挖地虎合体的实时 3D 动画

在夜间机库里，铲土机、搅拌机、拖斗、吊钩、清扫机、推土机六台工程车先后从大门驶入、停到位。合体指令下达后，六车依次变形、升空、对接、锁定，最后合成手持紫色步枪的大力神（Devastator）：抬头，双眼点亮，镜头低角度环绕，再拉远。全片 82 秒，配原创的帝国风进行曲。

形象参照 G1 大力神：
- 石灰绿车身，胸甲、双拳、膝、踝为紫色，大腿为灰色；
- 挖掘臂和铲斗脚在观众左侧，推铲和搅拌筒脚在观众右侧；
- 深色头盔、银色面甲、红色双眼，吊臂立在脑后；
- 右手（观众左侧）握紫色步枪，枪口朝下、向外；
- 狂派（霸天虎）徽标为紫底石灰绿线稿。

纯静态网页：HTML + CSS + 原生 ES Module + [Three.js 0.170](https://threejs.org/)（importmap 经 jsDelivr 加载），无构建步骤。所有模型、材质、纹理、音效和配乐都由代码程序生成，不加载任何贴图、模型或音频文件（只有用 `?bgm=` 指定自备录音时才会加载音频）。

> 同人致敬作品，非商业用途。Transformers（变形金刚）、Devastator 及各角色名称是 Hasbro, Inc. 的商标，本项目与 Hasbro 无关。

## 看点

| | |
|---|---|
| **六车各有变形** | 铲土机：车身竖立，铲斗翻成右脚<br>搅拌机：驾驶室后翻成左脚，搅拌筒成小腿<br>拖斗：整车横置，举斗后落下，紫色护裆滑出<br>吊钩：转台旋转，配重成胸甲，吊臂转到身后<br>清扫机：斗杆翻起高举，右拳伸出，紫色步枪从拳心弹出、前管伸长<br>推土机：推铲翻起成护盾，左拳伸出 |
| **合体顺序** | 按「腿 → 腰 → 胸 → 臂」自下而上装配，每 6.6 秒一名。每名成员都有独立运镜，锁定时有撞击闪光、扬尘和镜头震动 |
| **金属质感** | 车漆用带清漆层的 `MeshPhysicalMaterial`，另加金属漆片法线。钢件和轮毂用程序生成的磨损粗糙度图，液压杆和轮毂螺栓为镀铬。反射来自自建的 PMREM 灯箱环境：顶部灯带、两侧柔光墙、大门逆光和正面柔光箱 |
| **机库** | 混凝土地坪上有油渍、伸缩缝和裂纹，另有钢柱屋架、行车、高棚灯。开场时灯逐排亮起，合体时六盏警示旋转灯扫过 |
| **后期** | MSAA → GTAO 环境光遮蔽 → Bloom → ACES 色调映射。清漆和镀铬的高光在着色器里按项封顶，泛光输入也做了钳制，避免出现白斑或整屏光晕 |
| **界面** | 左侧名册显示各成员的状态（待命 / 行进 / 就位 / 变形 / 锁定）。右侧 LINK STATUS 示意图按部位点亮，底部是章节时间轴 |
| **狂派徽标** | 按 G1 线稿重绘：头盔轮廓、冠饰、眼窝、鼻梁、颊须和两侧下颌尖角，用偶奇填充在紫底上镂出石灰绿线条。同一套轮廓生成三维挤出件（吊钩胸甲、各车车门与车斗上的徽章）、地坪贴花的 Canvas 路径和界面上的 SVG 标志 |
| **识别模式** | 按 `X`，每名成员换上自己的识别色，便于看清哪台车成了哪个部位 |
| **音效** | WebAudio 实时合成柴油机、履带、液压、警报、对接撞击、棘轮、步枪展开和终场咆哮，并加机库混响 |
| **配乐** | 原创的 D 小调帝国风进行曲，WebAudio 实时合成铜管、圆号、低音、定音鼓、军鼓和镲。一拍 0.55 秒，每名成员的合体段正好三小节，六次锁定都落在小节强拍上：集结时低音固定型渐强，合体指令时鼓滚奏，合体段依次奏主题 A、主题 B，头部特写转入持续低音和定音鼓滚奏，英雄环绕时主题高八度齐奏后收在 D 小调长和弦。双眼点亮时配乐让出音量给咆哮声<br>没有使用《帝国进行曲》（John Williams 作曲，受版权保护）。如有授权录音，可以用 `?bgm=` 换上，见调试参数 |

## 运行

ES Module 需要经 HTTP 打开（`file://` 不行）：

```bash
cd ai-ml/chatgpt/claude/opus55-showcase
python3 -m http.server 8765
# 浏览器打开 http://localhost:8765/02-devastator/
```

首次打开要预编译着色器，等按钮显示「开始合体」后再点击。浏览器需要支持 WebGL 2。字体（站酷庆科黄油体、Chakra Petch、思源黑体）经 jsDelivr 加载；离线时退回系统字体，但 Three.js 同样经 CDN 加载，所以动画需要联网。

### 操作

| 操作 | 作用 |
|---|---|
| `空格` | 播放 / 暂停 |
| `←` / `→` | 后退 / 前进 5 秒 |
| `1`–`6` | 跳到第 *n* 名成员的合体段 |
| `C` 或「自由视角」 | 关闭运镜，改为鼠标拖拽环绕、滚轮缩放 |
| `X` 或「识别」 | 成员识别色 |
| `M` 或「声音」 | 开 / 关音效 |
| `Q` 或「高画质」 | 开 / 关 GTAO 和高像素比；机器吃力时可关掉 |
| 「0.5× / 1× / 1.5× / 2×」 | 播放速度 |
| 拖动时间轴、点名册 | 跳转 |

### 时间轴（1×）

| 时间 | 段落 |
|---|---|
| 0–5.2 s | 黑暗机库，顶灯由远及近亮起 |
| 5.2–19.6 s | 集结：六车两两驶入、停到位 |
| 19.6–24 s | 合体指令，警示灯转起 |
| 24–64.2 s | 六名成员依次合体。锁定时刻分别为：<br>铲土机 30 s、搅拌机 36.6 s、拖斗 43.2 s、吊钩 49.8 s、清扫机 56.4 s、推土机 63.0 s |
| 64.2–69 s | 头部特写：头盔升起，双眼点亮 |
| 69–82 s | 低角度英雄环绕，然后拉远 |

### 调试参数

| 参数 | 说明 | 例 |
|---|---|---|
| `dev` | 单体调试视图：只显示一名成员（或 `all`），可自由环绕 | `?dev=hook` |
| `u` | 与 `dev` 合用：变形进度 0–1 | `?dev=scavenger&u=0.5` |
| `dock` | 与 `dev` 合用：放到合体对接位 | `?dev=all&u=1&dock` |
| `sheet` | 与 `dev` 合用：四个姿态拼成联系表，`d` 后缀表示对接位 | `?dev=scrapper&sheet=0,0.4,0.7,1d` |
| `shot` | 保留绘图缓冲，便于截图 | `?shot` |
| `bgm` | 用自备录音替换合成配乐（http / https 地址，相对路径按页面解析）。录音随时间轴播放、暂停、跳转、变速，声音开关同样有效 | `?bgm=audio/march.mp3` |
| `bgmAt` | 与 `bgm` 合用：录音开头对应的时间轴秒数，默认 0 | `?bgm=audio/march.mp3&bgmAt=8` |

### 导出视频

`window.__app.exporter` 按固定帧间隔逐帧推进，不依赖实时帧率，导出的画面不会掉帧：

| 方法 | 作用 |
|---|---|
| `start(fps = 60)` | 停掉实时渲染循环，之后只由 `frame()` 推进 |
| `frame()` | 按当前播放速度前进 1/fps 秒并渲染一帧，返回时间轴秒数 |
| `audio(tail = 1)` | 用 OfflineAudioContext 按同样的帧节奏离线渲染完整音轨（音效 + 配乐，末尾多留 `tail` 秒余音），返回 32 位浮点 WAV 的 blob 地址 |

示例视频（1.5×，1080p60）的做法：
1. 用 Playwright 打开 `?shot`，视口设为 1920×1080，点 1.5× 和「开始合体」。
2. 用 `page.clock` 接管页面计时器，保证字幕的延时与画面同步；CSS 过渡用 `document.getAnimations()` 逐帧设置 `currentTime`。
3. 每帧依次执行 `frame()` 和截图，共 3281 帧；音轨用 `audio()` 渲染后下载。
4. 用 ffmpeg 合成，编码为 H.264（CRF 18）和 AAC；音轨先过 `alimiter`，因为锁定瞬间音效与配乐叠加，峰值会超过 0 dB。

        ├── hook.js         吊钩 → 胸部 · 头部

**渲染要点**
- 每名成员是一套分层骨架：车体、铰链、翻板各为一个节点，由一个 0–1 的变形进度驱动。车辆形态和机器人部件形态用的是同一组网格，只是折叠方式不同，所以变形过程是连续的，不是两套模型交叉淡入淡出。
- 每名成员有一个固定的对接位姿，写在大力神的整体坐标系里。成员先飞到对接位前方的预备点，再沿直线推入锁定。
- 时间轴是纯函数：任意时刻的姿态、镜头和灯光都由 `t` 直接算出，拖动时间轴与顺序播放的画面一致。
- 配乐与画面共用时间轴：乐谱按时间轴秒写好，每帧只把前方 0.2 秒内的音符排进音频时钟。拖动、暂停或变速时，已排的音符整批淡出，再从新位置接上；正跨过当前位置的长音从中段续上。所以跳转后听到的配乐与顺序播放一致，排谱开销约占实时运算的 4%。
- 平整的漆面和轮毂正对点光源时，GGX 高光峰值可达数百倍。`kit.js` 的 `tameSpec` 在着色器里分别给直射高光和环境高光封顶，只削峰、不改形状。地坪另有一档更低的封顶，避免油渍反光成白斑。

## 局限

- 模型由程序拼搭的盒体和圆柱组成，追求的是 G1 玩具那种积木感和可辨认的轮廓，不是影视级的高模。
- 变形顺序和部件折叠方式参照 G1 设定和玩具结构，细节上做了简化。
- 配乐用的是合成器音色，追求的是进行曲的节奏和气势，不是真实管弦乐录音的质感。
- 窄屏（< 1180px）时隐藏示意图，更窄时再依次隐藏章节条和名册。
