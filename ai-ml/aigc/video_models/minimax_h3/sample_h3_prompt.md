# MiniMax H3 中文提示词示例（H3-Base 原生格式）

本地部署的是 **H3-Base**，前面没有线上产品那层 H3-Context-IR 重写器，所以提示词要直接写成
模型训练时看到的**三字段结构**（见 `official_prompt_guide/VIDEO_PROMPT_WRITING_GUIDE_base_en.md`）。
描述正文用中文即可（文本编码器是 Qwen3-VL-32B），但下面这些**结构标记必须保留官方写法**：

| 标记 | 写法 | 说明 |
|---|---|---|
| 三个字段名 | `integrated_multimodal_description:` / `overall_soundscape:` / `non_diegetic_music:` | 顺序固定，字段间空一行 |
| 镜头 | `[Shot 1]`、`[Shot 2] At 00:04.500, 切至…` | 第一镜不写时间码；后续镜头时间码严格递增且在片长内 |
| 说话人 | `(S1)`、`(S2)`、合说 `(S1,S2)` | 只给会发声的人物编号，跨镜头保持不变 |
| 台词 | `<d>[Chinese] 台词原文</d>` | 语言标签 + 逐字台词；声线、动作写在 `<d>` **外面** |
| 旁白 | `以画外音旁白说道（says in an off-screen voiceover）：<d>…</d>`，随后**声明画内人物嘴唇闭合** | 否则模型可能把画内人物口型对到旁白上 |
| 运镜 | 中文 + 括注官方词：推进 Push In / 拉出 Pull Out / 横摇 Pan / 横移 Truck / 俯仰 Tilt / 升降 Pedestal / 环绕 Arc Shot / 跟拍 Tracking Shot / 固定 Static Shot / 轻微抖动 Shake Slightly；幅度 `small/large amplitude`，速度 `slow/fast speed` | 写成句子里的动作，不要堆在句尾 |
| 画面文字 | 英文双引号 `"营业中"` | 原文原标点，不翻译 |
| 跨镜头台词 / 被截断 | `<scenetrans>` / `<cutoff>` | |

三个字段各放什么：

- **integrated_multimodal_description**：沿时间线写画面——开头先给风格（实拍 live-action / 电影感 cinematic / 2D 动画 / 3D CG / 黏土 claymation / 水彩 / 胶片）和初始构图，然后是主体外观、场景、动作、运镜、说话人、台词、**画内**声音（角色能听到的音乐、电视、电话铃等也在这里）。
- **overall_soundscape**：1–4 句，全片的环境音、动作音、非语言人声（风雨车流、脚步、衣料摩擦、呼吸、笑声）。**不要重复台词**。全片静音才写 `N/A`。
- **non_diegetic_music**：1–3 句，只有观众听得到的配乐——写乐器、速度、节奏、动态变化，**不写情绪词**。没有配乐写 `N/A`。

旧模板里的字段怎么迁移：【主题】【主体】【场景】【镜头】【光线】【色彩】全部融进 `[Shot 1]` 的描述；
【声音】拆成台词（进描述）、环境/音效（进 soundscape）、配乐（进 music）；【节奏】变成时间码；
【画质】里的"2K / 24fps / 无闪烁"**不要写**——H3-Base 固定 24fps、768p 输出，2K 要靠未开源的 Regenerate-2K，
这些词只会占 token。时长、画幅、分辨率是 API 参数，不在提示词里。

语速参考：中文约 2.5–3 字/秒，英文约 2.5 词/秒。5 秒放一短句，8 秒两句，15 秒一小段。

## 1. 雪山日出举旗（8 秒，无台词）

```
integrated_multimodal_description: [Shot 1] 实拍，电影感，低角度仰拍的中全景：一位中年中国男性登山者站在八千米雪山之巅，红色羽绒服、背登山包，面罩下拉露出冻红的脸，表情疲惫但坚定。日出06:00，天空蓝金渐变，脚下云海翻涌，远处群山覆雪连绵。正前方日出逆光勾出人物金色轮廓，雪面反射金光，天空的蓝光从侧面补亮脸部，高反差硬光。前3秒他双手把一面中国国旗举过头顶，旗面被强风猛烈扯开；随后5秒旗在风中持续剧烈飘动，镜头保持仰角并缓慢向上横摇至天空（pan up with small amplitude at slow speed），人物逐渐落到画面下缘，金光占满上半画面。

overall_soundscape: 强风持续呼啸，左右声道带山间回旋感；旗面布料在风中密集啪啪抖动，登山者粗重的呼吸声居中；左后方偶有远处雪崩的低沉闷响。山顶开阔无反射。

non_diegetic_music: N/A
```

## 2. 老巷修表匠（10 秒，无台词）

```
integrated_multimodal_description: [Shot 1] 实拍，电影感，浅景深近景特写：老巷深处一张木工作台，65岁中国男性白发稀疏、戴老花镜、穿灰色对襟中山装，低头用镊子夹起一枚微小零件放入表芯，手指微颤但落点精准。桌面有放大镜和散落的金属零件，墙上一只旧挂钟，地面是石板。右侧木窗格子斜阳照入，3200K暖黄硬光，光束中灰尘粒子清晰可见形成体积光，画面整体暖棕低饱和、胶片褪色质感。镜头固定（static shot），仅在前8秒极缓慢地小幅推进（push in with small amplitude at slow speed）到他的双手；最后2秒他放下镊子，抬头看向窗外一瞬，镜头停住。

overall_soundscape: 多只钟表不同频率的滴答声叠在前方持续；镊子夹零件的细小金属声、零件偶尔落入瓷盘的清脆叮声随动作出现；左后方极弱的街市嘈杂，右后方偶有一声自行车铃。小房间轻微反射。

non_diegetic_music: N/A
```

## 3. 樱花树下少女转身离去（10 秒，画内台词，2D 动画）

```
integrated_multimodal_description: [Shot 1] 2D赛璐珞动画，线条纤细、两层上色、日系柔和高饱和。中景：樱花大道午后15:00，柔光漫射，花瓣漫天飘落、地面铺满粉色花瓣，远处有鸟居和蓝天白云。16岁少女，樱花粉色长发及腰、白色发带、水手服（白上衣蓝领、深蓝裙），手提书包背对镜头站在樱花树下。前3秒她转身面向镜头，发丝和裙摆随动作扬起，花瓣在逆光中半透明发亮，人物边缘有柔光晕；镜头缓慢推进并跟随（push in with small amplitude at slow speed, tracking shot）从中景到近景。第3到6秒她温柔微笑、眼里有光点，这位声音清亮柔和、语速轻缓的少女（S1）看着镜头说：<d>[Chinese] 您好，请多关照，今天是樱花季节。</d> 口型与台词同步。最后4秒她转身沿大道往前走远，镜头停止跟随，背影在飘落的花瓣中变小。

overall_soundscape: 微风轻拂左右声道，花瓣落地的细碎沙沙声在前方持续，少女转身时裙摆布料的轻响，右后方远处鸟鸣。开阔空间轻微反射。

non_diegetic_music: 轻柔的钢琴与弦乐慢速铺底，从第1秒极轻渐入，台词期间保持在人声之下，少女走远时音量略升并在结尾自然收束。
```

## 4. 宠物小怪物卧室冒险（10 秒，画内台词，萌系动画）

```
integrated_multimodal_description: [Shot 1] 2D赛璐珞动画，圆润线条，萌系柔和暖调。低角度近景手持跟拍（handheld tracking shot, shake slightly）：儿童卧室木质地板，积木和绘本散落，右侧窗户透入6000K冷白月光在地板上投出窗格阴影，床下有一圈暖黄微光。一只直径约30厘米的圆球形绿色小怪物，大眼睛小嘴，头顶一片小叶子，短手短脚，前4秒在地板上连蹦三下探索，每次落地身体微微压扁回弹；第4到7秒它好奇地凑近一只拖鞋，用短手碰了碰，拖鞋歪倒；第7秒它转向镜头，这只声音细软、带点电子感、语速欢快的小怪物（S1）说：<d>[Chinese] 我是宇宙超级无敌圆球形绿色小怪物！</d> 说话时小嘴开合与台词同步，说完歪头眨眼。最后1秒镜头停住。

overall_soundscape: 卧室极安静，窗外偶有虫鸣；小怪物每次蹦跳落地有短促的"啵"声，碰拖鞋时有布料摩擦声，转身时有一声好奇的"咿？"。小房间轻微反射。

non_diegetic_music: 木琴与拨弦乐器的轻快短句，中等偏慢速度，跳跃时与落地节拍对齐，台词期间退到很轻。
```

## 5. 赛博朋克街景（14 秒，无台词，两镜头）

```
integrated_multimodal_description: [Shot 1] 实拍质感，电影感，24mm广角大远景：未来亚洲都市深夜雨后的狭窄巷道，两侧高楼密布霓虹招牌（中文、日文、韩文混杂，紫、品红、青、绿），地面湿滑映出霓虹倒影，排气口不断冒出蒸汽，光束在蒸汽中散射成体积光，巷道尽头有一块全息广告巨幕。整体冷紫洋红主调、青绿霓虹辅色、高饱和高对比。镜头沿巷道中线缓慢推进（push in with small amplitude at slow speed），一辆飞行器的灯光掠过头顶。[Shot 2] At 00:08.000, 切至巷道深处的中景：一块写着 "营业中" 的红色霓虹招牌在雨后水洼中倒映，蒸汽从下方涌上遮住招牌又散开，镜头微微向上仰起（tilt up with small amplitude at slow speed）露出更高处层叠的招牌，持续到结尾。

overall_soundscape: 霓虹招牌的电流嗡嗡声散布在左右声道，排气口的蒸汽嘶嘶声在前方间歇出现，远处全息广告的播报声在左后方模糊不清，第3秒左右一架飞行器从头顶掠过的呼啸由右至左。窄巷轻微反射，全程无人声。

non_diegetic_music: 低频电子氛围持续脉动，慢速，合成器长音在第二镜头切换时略微加厚，结尾不收束保持悬停。
```

## 6. 电商带货口播（14 秒，画内台词，语速快）

```
integrated_multimodal_description: [Shot 1] 实拍，直播间风格，50mm中近景固定镜头（static shot），f/1.8背景虚化：25岁中国女性主播，妆容精致自然，白色简约上衣，坐在桌前，桌面陈列几瓶护肤品，背景是虚化的暖光货架，前景补光环在她瞳孔里映出环形反光，4500K柔光、暖白主调。她手持一瓶护肤品面向镜头，表情热情真诚，边说边用手指点向瓶身细节。这位声音清亮、语速快、富有感染力的年轻女主播（S1）看着镜头说：<d>[Chinese] 走过路过不要错过，今天促销最后 10 件！</d> 口型与台词精准同步；说完她把瓶子往镜头前递了递，拧开瓶盖展示质地，然后放回桌面，微笑点头。

overall_soundscape: 直播间极安静，只有她拧开瓶盖的轻响和瓶子放回桌面的一声轻叩，偶有拆包装塑料膜的沙沙声。无混响干声。

non_diegetic_music: N/A
```

## 7. 江南水乡纪录片旁白（8 秒，画外音）

旁白的完整规则见 `prompt_examples.md` 的"Narration / voice-over"一节。要点：`(S1)` + 声线描述在 `<d>` 外、
原话 `says in an off-screen voiceover`、`<d>` 之后紧跟"画内人物嘴唇闭合"、用时间码锚定起止。

```
integrated_multimodal_description: [Shot 1] 实拍，电影感，全景：清晨的江南水乡，薄雾贴着河面，两岸白墙黛瓦，一座石拱桥倒映在静止的水面。一位老船夫穿深蓝布衫戴斗笠，站在小木船船尾缓慢撑桨，船头划开薄雾。右侧低角度晨光，4500K柔光，水面有细碎反光，整体青灰主调、低饱和纪录片质感。镜头朝他缓慢小幅推进（push in with small amplitude at slow speed）。从 00:01.000 开始，一位声音低沉、温暖、语速缓慢的中年男性（S1）以画外音旁白说道（says in an off-screen voiceover）：<d>[Chinese] 天还没亮透，河面上只有一条船。老李已经在这条水路上摇了四十年。</d> 期间画面里的船夫嘴唇始终闭合，继续撑桨。旁白在 00:07.000 前结束，小船穿过桥洞，镜头停住。

overall_soundscape: 水轻拍木船船身，船桨入水声缓慢而有节奏地在前方重复；远处鸟鸣飘过水面，小镇其余部分安静。

non_diegetic_music: 一把古筝弹奏稀疏、缓慢、长延音的单音，音量在旁白之下很轻，最后一秒淡出。
```
