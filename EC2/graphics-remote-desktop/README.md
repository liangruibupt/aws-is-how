# EC2 Graphics Workstation & Remote Desktop (NICE DCV)

在 GPU 实例上搭建图形工作站，并通过 NICE DCV 远程访问 Linux / Windows 桌面。

## Docs

- [Linux-NICE-DCV-Servers-on-Amazon-EC2](Linux-NICE-DCV-Servers-on-Amazon-EC2.md)：Amazon Linux 2 上安装桌面环境和 NVIDIA GRID 驱动、配置 X Server，安装 NICE DCV Server、创建 console / virtual 会话并用 DCV Client 连接
- [Windows-NICE-DCV-Servers-on-Amazon-EC2](Windows-NICE-DCV-Servers-on-Amazon-EC2.md)：G4 + Windows Server 2016 安装 NICE DCV Server：中国区 DCV license 的 S3 IAM policy、安装选项、开放 8443 端口、DCV Client 连接
- [Windows-Graphics-Workstation-on-Amazon-EC2](Windows-Graphics-Workstation-on-Amazon-EC2.md)：G4 + Windows Server 2016 搭建图形工作站：NVIDIA Tesla / GRID 驱动选择与安装、GPU 时钟优化、Windows 媒体组件、禁用默认显卡、FurMark 3D 测试
